# Blinky for STM32

---

This project was made in order to learn basics of ARM architecture and to introduce myself to STM32 registers and workflow.

### What have I done?

- Familiarize myself with Reference Manual.
- Learn basic registers and what registers need to be configured to fullfil basic functionalities.
- Implemented a `dleay_ms.c` module to provide a delay functionality. It can be easily used in future programs since it was made with portability in mind.

### What have I learned?

- Familiarize myself with Reference Manual.
- Learn basic registers and what registers need to be configured to fullfil basic functionalities.
- Learned how to made my own modules for future projects.
- Learned basics of STM32CubeIDE.

### Hardware Connection:

- No hardware connections were required.
